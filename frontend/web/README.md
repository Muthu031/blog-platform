# ProjectPal - Production-Ready Multi-Tenant Project Management UI

A modern, scalable multi-tenant project management web application UI built with React.js, TypeScript, and Tailwind CSS.

## Quick Start

```bash
cd frontend/web
npm install
npm run dev
```

Visit `http://localhost:5173`

## Features

- **Authentication**: Login, signup, forgot password
- **Multi-Tenant**: Organizations with role-based access
- **Projects**: Create and manage projects
- **Kanban Board**: Drag-and-drop task management
- **Tasks**: Full task lifecycle with comments
- **Enterprise UI**: Professional Tailwind CSS design

## Tech Stack

React 18 • TypeScript • Tailwind CSS • Zustand • TanStack Query • React Hook Form • Axios
