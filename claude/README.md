# 📚 Multi-Tenant SaaS Learning Path

This directory contains structured tasks and lessons for building the Multi-Tenant SaaS Project Management Platform.

## 📁 Structure

```
claude/
├── README.md           # This file
└── tasks/              # Lesson-by-lesson tasks
    ├── phase-1/        # Core CRUD (Weeks 1-2)
    ├── phase-2/        # Permissions & RBAC (Week 3)
    ├── phase-3/        # Real-Time & Notifications (Week 4)
    ├── phase-4/        # Caching & Optimization (Week 5)
    ├── phase-5/        # File Uploads & Background Jobs (Week 6)
    ├── phase-6/        # Deployment & CI/CD (Week 7)
    └── phase-7/        # Testing & Refactoring (Week 8)
```

## 🎯 How to Use

1. **Start with Phase 1**: Begin with `tasks/phase-1/lesson-01.md`
2. **Follow Sequential Order**: Complete lessons in order (they build on each other)
3. **Check Off Progress**: Mark completed lessons in your tracker
4. **Reference Main Docs**: Refer to `../claude.md` for detailed architecture decisions
