# Reverse Linked List

Difficulty: Easy

Description:
Reverse a singly linked list and return the head of the reversed list.

Input: `1 -> 2 -> 3 -> 4 -> 5 -> NULL`

Output: `5 -> 4 -> 3 -> 2 -> 1 -> NULL`

Hints:
- Use iterative approach with three pointers: prev, curr, next.
- Recursive solution exists but uses extra call stack space.
