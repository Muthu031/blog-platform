# Merge Two Sorted Lists

Difficulty: Easy

Description:
Merge two sorted linked lists and return it as a new sorted list. The list should be made by splicing together the nodes of the first two lists.

Input: `l1 = [1,2,4], l2 = [1,3,4]`

Output: `[1,1,2,3,4,4]`

Hints:
- Use a dummy head and a tail pointer to build the merged list iteratively.
- Compare current nodes of both lists and append the smaller one.

Tags: Linked List
