# Intersection of Two Arrays

Difficulty: Easy

Description:
Given two arrays, return an array of their intersection. Each element in the result must be unique. Order does not matter.

Input: `nums1 = [1,2,2,1], nums2 = [2,2]`

Output: `[2]`

Hints:
- Use a set for one array and check membership for the other to collect unique intersections.
- For repeated elements (not unique result), use a map to count frequencies.

Tags: HashMap, Set
