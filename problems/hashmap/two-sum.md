# Two Sum (HashMap)

Difficulty: Easy

Description:
Same as the Arrays `Two Sum` problem; included here for HashMap practice.

Input: `nums = [2,7,11,15], target = 9`

Output: `[0,1]`

Hints:
- Use a hash map to remember indices of seen values; check complement during one pass.
- This yields O(n) time and O(n) space.
