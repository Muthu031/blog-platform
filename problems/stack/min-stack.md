# Min Stack

Difficulty: Easy

Description:
Design a stack that supports push, pop, top, and retrieving the minimum element in constant time.

Operations: `push(x)`, `pop()`, `top()`, `getMin()`

Hints:
- Keep an auxiliary stack that tracks the minimum at each depth or store pairs `(value, currentMin)`.
- Ensure `getMin()` is O(1) and maintains correct value on `pop()`.

Tags: Stack, Design
