# Valid Anagram

Difficulty: Easy

Description:
Given two strings `s` and `t`, return `true` if `t` is an anagram of `s`, and `false` otherwise.

Input: `s = "anagram", t = "nagaram"`

Output: `true`

Hints:
- Count characters using a fixed-size array (for ASCII) or a hash map.
- You can sort both strings and compare; that's O(n log n).

Tags: Strings, HashMap
